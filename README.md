# Cellmate Connections Codex

A practical, evolving guide to designing, documenting, and maintaining reliable connections between cellmates, communities, and supporting systems.

## Purpose

This codex provides shared language, safety principles, connection patterns, and reusable documentation templates for people building or facilitating cellmate connections. It is intentionally platform-neutral and should be adapted to local law, policy, culture, and operational needs.

## Principles

1. **Safety first** — Protect physical, emotional, legal, and digital safety.
2. **Consent and agency** — Participation is voluntary, informed, and revocable.
3. **Privacy by design** — Collect the minimum information needed and explain how it is used.
4. **Accessibility** — Design for different abilities, languages, literacy levels, and technology access.
5. **Dignity and respect** — Use person-first, non-stigmatizing language.
6. **Accountability** — Make responsibilities, reporting paths, and decisions visible.
7. **Trauma-informed practice** — Avoid coercion, unnecessary exposure, and preventable retraumatization.
8. **Continuous learning** — Review outcomes, listen to participants, and improve the system.
