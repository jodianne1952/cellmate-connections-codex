# Getting started

## 1. Define the connection

Document who is connecting, why the connection exists, what each participant can expect, and what is explicitly out of scope. Keep the description understandable to someone encountering the program for the first time.

## 2. Identify stakeholders

Consider participants, facilitators, family or support networks, service providers, oversight bodies, and people affected indirectly. Give each group a clear way to ask questions or raise concerns.

## 3. Establish informed consent

Before a connection begins, explain:

- the purpose and expected duration;
- what information will be shared and with whom;
- foreseeable risks and benefits;
- available alternatives;
- how to pause or end participation; and
- how concerns or incidents will be handled.

Consent should never be assumed from silence, prior participation, or access to a service.

## 4. Start with the minimum viable exchange

Share only the information and access needed for the immediate purpose. Prefer reversible steps, limited visibility, and time-bounded permissions.

## 5. Check in and document learning

Use regular, low-burden check-ins. Record decisions and aggregate lessons without exposing participant identities. Update the protocol when risks, technology, or participant needs change.

## Readiness checklist

- [ ] Purpose and scope are written down.
- [ ] Roles and escalation contacts are identified.
- [ ] Consent and withdrawal processes are accessible.
- [ ] Privacy and retention rules are defined.
- [ ] Safety risks have been assessed.
- [ ] Accessibility needs have been considered.
- [ ] A review date has been scheduled.
